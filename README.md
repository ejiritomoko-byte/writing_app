# writing_app

`Note`、`X`、ブログ系、`Instagram`、`Threads` 向けの下書きを、方針確認を挟んで作るためのフロント試作です。

## できること

- `Note` / `X` / `WordPress` / `Amebaブログ` / `Instagram` / `Threads` の選択
- キーワード、ざっくりした内容、入れたい要素だけの入力
- ユーザー層やアカウント設定に応じた文体・構成の出し分け
- 媒体ごとの `文字数目安` `ハッシュタグ方針` `見出し数` `CTAの強さ` の設定
- `Googleトレンド` / `公式ニュース` などの確認チェック
- 調査メモをもとにした方針プレビュー
- 方針の手動修正後、そのまま本文生成
- 設定画面でのアカウント追加・編集・削除

## 使い方

`index.html` をブラウザで開くとそのまま使えます。

## 補足

現状は静的デモです。`Googleトレンド` や公式ニュースの自動取得はまだ未接続で、確認メモを入力して使う形になっています。
